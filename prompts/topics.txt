Topic labeling 
You are an expert annotator. Your task is to assign a topic label to each User A turn in a two-party conversation. Use both User A's message and User B's response to determine the topic.

Return ONLY valid JSON; do not include explanations outside JSON.

## Topic taxonomy
Assign the single most appropriate topic from the following list (exact strings):

- **Uncategorized**: does not fit any of the above categories, or is too ambiguous to classify


## Decision rules:
1. Assign one topic label per User A turn based on what User A is asking about, using both sides of the conversation to determine the topic.
2. For short or ambiguous User A turns (e.g. "Yes", "Go on", "Thanks", "Can you help me with this?"), assign the topic that best fits the surrounding turns — do not default to Uncategorized.
3. If a turn covers multiple topics, assign the most prominent one.
4. If User A is asking to produce fictional or artistic content (story, poem, script, fiction), label it **Creative Writing**. If the writing requested is functional (email, cover letter, template, report), label it based on the subject matter of that content.
5. Assign confidence 0.9–1.0 when the topic is unambiguous, 0.7–0.89 when the topic is clear but the turn is short or partially ambiguous, and below 0.7 when the turn is genuinely unclear or spans multiple topics.

## Output JSON schema (and nothing else):

  "data_per_turn": [
    {
      "turn_index": <int, 0-based>,
      "topic": "<topic label>",
      "confidence": <float between 0 and 1>
    }
  ]
